## 🌟 Overview
The **Asset Management Client** is a high-performance React application built on **Vite**. It provides a centralized ecosystem for managing company hardware and resources. By integrating role-based access control (RBAC), the platform ensures that Employees, Managers, and HR personnel have the specific tools they need to request, approve, and analyze asset lifecycles.

## 🚀 Key Features

* **🔐 Role-Based Portals:** Tailored experiences for **Employees** (Requests), **Managers** (Approvals), and **HR** (Inventory Control).
* **📈 Visual Analytics:** Dynamic charts and usage trends powered by **Recharts**.
* **⚡ Real-time State:** Instant UI updates and caching using **TanStack Query**.
* **🎨 Fluid Design:** A fully responsive, accessible UI featuring **Radix UI** primitives and **DaisyUI** components.
* **🎭 Interactive Flows:** Visual asset relationship mapping via **React Flow**.
* **🔔 Smart Notifications:** Beautiful alerts and confirmations using **SweetAlert2**.

## 🛠️ Tech Stack

### **Core Engine**
| Library | Purpose |
| :--- | :--- |
| **React 18** | Component-based UI development |
| **Vite** | Lightning-fast build tool and HMR |
| **TanStack Query** | Server-state management & data fetching |
| **Firebase** | Authentication & Cloud services |
| **Axios** | Promise-based HTTP client |

* **Styling:** Tailwind CSS + Styled Components + DaisyUI.
* **Components:** Radix UI (Accessible primitives).

### **Form & Utility**
* **Forms:** React Hook Form.
* **Date Handling:** Moment.js.
* **Feedback:** SweetAlert2 & React Tooltip.

## 🏗️ Getting Started

### **Prerequisites**
* **Node.js** (v18.0.0 or higher)
* **npm** or **yarn**

### **Setup Instructions**

1.  **Clone the Repository**
    ```bash
    git clone [https://github.com/yourusername/asset-management-client.git](https://github.com/yourusername/asset-management-client.git)
    cd asset-management-client
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Configure Environment Variables**
    Create a `.env` file in the root directory and add your Firebase/API keys:
    ```env
    VITE_FIREBASE_API_KEY=your_api_key
    VITE_API_BASE_URL=your_backend_url
    ```

4.  **Run Development Server**
    ```bash
    npm run dev
    ```
